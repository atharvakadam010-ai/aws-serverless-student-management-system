# aws-serverless-student-management-system
Serverless Student Management System using AWS Lambda, API Gateway, DynamoDB and S3
WS Serverless Student Management System

Project Overview

This project is a serverless Student Management System built using AWS services.

AWS Services Used

* AWS Lambda
* API Gateway
* DynamoDB
* IAM
* CloudWatch
* Amazon S3

Features

* Add Student Record
* Retrieve Student Record
* Serverless Architecture
* REST API Integration
* Cloud Monitoring

Architecture

User → Frontend (HTML/JavaScript) → API Gateway → Lambda → DynamoDB

Technologies

* HTML
* JavaScript
* AWS Lambda
* DynamoDB
* API Gateway
* CloudWatch
* Postman
